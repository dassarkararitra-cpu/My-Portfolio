## 🌐 Deployment on Netlify

This project is perfectly optimized for Netlify's free tier. 

1. Push this code to your GitHub repository.
2. Log in to [Netlify](https://app.netlify.com/).
3. Click on **Add new site** > **Import an existing project**.
4. Connect your GitHub account and select this repository.
5. Leave the **Build command** and **Publish directory** empty (it's just a static HTML file).
6. Click **Deploy site**.

Within seconds, your portfolio will be live on the internet!
